# 卒業単位計算機

関東学院大学 理工学部 理工学科 情報ネット・メディアコース向けの卒業単位計算機です。

対象: 2023～2025年度入学 情報ネット・メディアコース生

## 動作環境

- Windows 10
- Windows 11

## 起動方法（利用者向け）

1. GitHub Releasesから `sotsugyo-tani-keisanki-v1.6.1.exe` をダウンロードします。
2. ダウンロードした `.exe` をダブルクリックしてインストールします。
3. Windowsの警告が出た場合は、「詳細情報」を押してから「実行」を押します。

Releaseページ: https://github.com/Uryo0/sotsugyo-tani-keisanki/releases/tag/v1.6.1

## ダウンロード

sotsugyo-tani-keisanki-v1.6.1.exe をダウンロードして、ダブルクリックで起動してください。

## 自動更新

v1.6.0以降は、アプリ起動時に新しいバージョンがあるか自動で確認します。
更新の準備ができたら、アプリを再起動して更新できます。

v1.6.0を使っている場合は、アプリ起動時にv1.6.1へ更新できます。

v1.5.0以前のportable版を使っている場合は、自動更新されません。
一度 `sotsugyo-tani-keisanki-v1.6.1.exe` をダウンロードしてインストールしてください。

## Windowsの警告が出た場合

このアプリは個人で作成しているため、初回起動時にWindowsの警告が出る場合があります。
その場合は、表示内容を確認してから「詳細情報」→「実行」の順に押してください。

## 注意

- 本アプリの計算結果は参考値です。正式な卒業判定は必ず大学の成績表・履修要綱で確認してください。
- 本アプリは修得済み単位の計算のみを行います。登録必須科目の登録義務、卒業研究の履修資格、履修制限単位数などは判定できません。
- 成績表で単位を修得した科目のみチェックしてください。不可の科目は含めないでください。検定等で単位認定を受けた科目は修得済みとしてチェックしてください。

## 開発者向けの起動方法

ソースコードから動かす場合だけ、次のコマンドを使います。

```bash
npm install
npm start
```

配布用の `.exe` を作り直す場合は、次のコマンドを使います。

```bash
npm run dist
```

## 主な機能

- 科目をチェックして修得済みにする
- 卒業に必要な単位数を自動で計算する
- 総単位と主な不足項目を上部に表示する
- 未修得の必修科目を表示する
- 不足している選択必修と候補科目を表示する
- 単位表示の「同一外国語科目」でメインにする外国語を選択する
- 科目名と旧科目名で検索する
- 検索・絞り込みをまとめて解除する
- 選択済み科目の行を色で表示する
- アプリ画面から科目を追加する
- 追加した科目だけを削除する
- 自主選択学修に直接入る科目を計算する
- 選択状態と追加科目を保存する

## 追加科目のID

アプリ画面から追加した科目には、追加した順に `add001`、`add002` のようなIDを付けます。
一度付けたIDは、追加科目を削除しても変更しません。
例えば、`add001` と `add002` がある状態で `add001` を削除しても、`add002` は `add002` のままです。次に追加する科目は `add003` になります。

## 外国語科目の計算

メイン外国語に選んだ言語だけを、外国語科目の選択必修4単位に使います。

例として、メイン外国語を英語にした場合です。

- 英語4単位、ドイツ語2単位を修得した場合、ドイツ語2単位は自主選択学修に入ります。
- 英語5単位を修得した場合、英語4単位は外国語科目の選択必修に入り、余った英語1単位は自主選択学修に入ります。

教養科目の選択必修科目も、2単位を超えた分は自主選択学修に入ります。

## 科目データについて

専門応用科目には `course` を入れています。`field` は「プログラミング」「メディア工学」など、履修要項の分野を書きます。
他コースの専門応用科目は、他コースで必修や登録必須でも、情報ネット・メディアコース用の計算では `requirement_type` を「選択」にしています。
情報ネット・メディアコースと同じ科目名の他コース科目は追加せず、情報ネット・メディアコースの科目として扱います。
他コースの卒業研究関連科目、実験・実習・実技の科目、他学部開講科目は、理工学科専門応用科目の単位には入れず、自主選択学修の単位として扱います。

自主選択学修として直接扱う科目には、`counts_as` に「自主選択学修」を入れています。日本語、海外語学演習、数学基礎Ⅰ・Ⅱなどが対象です。
