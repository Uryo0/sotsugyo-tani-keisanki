# 卒業単位計算機

関東学院大学 理工学部 理工学科 情報ネット・メディアコース向けの卒業単位計算機です。

## 起動方法（利用者向け）

1. GitHub Releasesから `sotsugyo-tani-keisanki-v1.0.0.exe` をダウンロードします。
2. ダウンロードした `.exe` をダブルクリックします。
3. Windowsの警告が出た場合は、内容を確認して実行します。

Releaseページ: https://github.com/Uryo0/sotsugyo-tani-keisanki/releases/tag/v1.0.0

## 開発者向けの起動方法

ソースコードから動かす場合だけ、次のコマンドを使います。

```bash
npm install
npm start
```

完成版の `.exe` を作り直す場合は、次のコマンドを使います。

```bash
npm run dist
```

## 主な機能

- 科目をチェックして修得済みにする
- 卒業に必要な単位数を自動で計算する
- 未修得の必修科目を表示する
- 単位表示の「同一外国語科目」でメインにする外国語を選択する
- 科目名と旧科目名で検索する
- アプリ画面から科目を追加する
- 追加した科目だけを削除する
- 選択状態と追加科目を保存する

## 追加科目のID

アプリ画面から追加した科目には、追加した順に `add001`、`add002` のようなIDを付けます。
追加科目を削除した場合は、残った追加科目のIDを `add001` から順番に付け直します。
例えば、`add001` と `add002` がある状態で `add001` を削除すると、`add002` は `add001` になります。

## 外国語科目の計算

メイン外国語に選んだ言語だけを、外国語科目の選択必修4単位に使います。

例として、メイン外国語を英語にした場合です。

- 英語4単位、ドイツ語2単位を修得した場合、ドイツ語2単位は自主選択学修に入ります。
- 英語5単位を修得した場合、英語4単位は外国語科目の選択必修に入り、余った英語1単位は自主選択学修に入ります。

教養科目の選択必修科目も、2単位を超えた分は自主選択学修に入ります。
