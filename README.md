# 卒業単位計算機

関東学院大学 理工学部 理工学科 情報ネット・メディアコース向けの卒業単位計算機です。

## 起動方法

```bash
npm install
npm start
```

## 主な機能

- 科目をチェックして修得済みにする
- 卒業に必要な単位数を自動で計算する
- 未修得の必修科目を表示する
- メインにする外国語を選択する
- 選択状態を保存する
- JSONファイルとして保存、読み込みする

## 外国語の計算

メイン外国語に選んだ言語だけを、外国語の選択必修4単位に使います。

例として、メイン外国語を英語にした場合です。

- 英語4単位、ドイツ語2単位を修得した場合、ドイツ語2単位は自主選択学修に入ります。
- 英語5単位を修得した場合、4単位は外国語の選択必修に入り、余った1単位は自主選択学修に入ります。

教養選択必修も2単位を超えた分は自主選択学修に入ります。
